# IPL Data Analysis using Python
## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Indian Premier League (IPL) matches dataset using Python. The analysis provides insights into team performance, player achievements, toss results, and winning patterns through data visualization.
---
## Dataset
Dataset Used:- matches.csv

The dataset contains IPL match information including:

- Season
- City
- Teams
- Toss Winner
- Match Winner
- Player of the Match
- Win by Runs
- Win by Wickets

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

---

## Project Objectives

The project answers questions such as:

- Which players won the most Player of the Match awards?
- Which teams won the most matches?
- Which teams won after batting first?
- Which teams won while chasing?
- Distribution of winning margins by runs.
- Distribution of winning margins by wickets.
- Toss winner analysis.
- Does winning the toss increase the chances of winning the match?

---


## Visualizations

The notebook includes:

- Bar Charts
- Histograms
- Pie Charts

---

## Key Insights

- Top players with the most Player of the Match awards.
- Most successful IPL teams.
- Batting first vs batting second winning trends.
- Toss winner analysis.
- Winning margin distributions.
